# Bountixx Brand System

## Core character

Ruthless, kinetic, underground. Bountixx feels like a late-night hackathon in a brutalist server room: competent, competitive, and visibly high-stakes.

## Existing visual anchors to preserve

- Crown mark, gold crown color, dark native environment, dense information surfaces.
- Zen Dots for titles, Rajdhani for body, Space Mono for data labels, Orbitron for UI chrome.
- The phrase `claim the crown` remains part of the casual Arena identity.

## Community Rush expression

Community Rush adds a precise proof-and-vault layer, not generic blockchain imagery. Use stars, constellations, transaction lines, and proof states sparingly. Never replace Bountixx's crown with Stellar's mark or imply Stellar endorsement.

## Content rules

- Say `Crowns` for internal non-transferable points.
- Say `XLM` or `Lumen Reward` only for actual Stellar network payouts.
- Say `sponsor-funded` for a Rush Vault.
- Prefer `verified`, `locked`, `funded`, `settled`, and `proved` to vague crypto language.
- Do not use `stake`, `bet`, `wager`, or `jackpot` for Community Rush rewards.

## Design direction

Product UI is dark, dense, and sharp. Community Rush should introduce an identifiable gold-to-starlight accent treatment only in verified surfaces; it must not become a purple-gradient crypto dashboard. Preserve reduced-motion and accessible contrast behavior.
