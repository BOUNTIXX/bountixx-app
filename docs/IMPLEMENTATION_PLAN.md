# Community Rush Delivery Plan

## Stage 1: Product foundation

- Preserve every existing Arena route and its Crown economy.
- Add Community Rush navigation, campaign discovery, and a Stellar Builder Rush fixture.
- Add a verified/non-verified distinction with explicit sponsor and proof states.

## Stage 2: Stellar Testnet connection

- Connect a Stellar wallet only from a verified action.
- Display address, network, and Testnet status without blocking casual play.
- Use the Rush SDK for campaign manifests and proof data.

## Stage 3: Settlement integration

- Create sponsor-funded Testnet Rush Vaults.
- Send deterministic results to the verifier.
- Show a result proof and payout status in the app.

## Stage 4: Open-source readiness

- Add tests, deployment documentation, and contributor setup.
- Publish genuinely scoped issues across the app and contracts repositories.
- Apply to Stellar Wave only after the Testnet flow is demonstrable end-to-end.

## Success criteria

A casual player can use Bountixx without a wallet. A community organizer can show a Sponsor-funded Stellar Builder Rush whose immutable rules, prize status, and verifiable completion are visible in the product.
